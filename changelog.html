A record of new tools, formula calibrations, data updates and site-structure changes. Verification results are added here as the game updates.

September 2, 2026

  • Launched Generation stats: rally-leader Bear Hunt builds (INF/LAN/MKS) aggregated per generation from user submissions, shown alongside theoretical best builds per spending tier. Added a submission page and one-click submission from the simulator.
  • Extracted the simulator's calculation core into a shared module (bear-calc.js). Results are unchanged (2,113-case regression test).
