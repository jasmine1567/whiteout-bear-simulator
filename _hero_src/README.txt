ここに英雄アイコンの画像を入れます（png / jpg / webp）。
ファイル名は 英雄ID（jeronimo.png）・日本語名（ジェロニモ.png）・英語名（Jeronimo.png）のどれでも構いません。
（いま入っている画像は、zip を展開したときに文字化けしないよう英雄IDの名前にしてあります）
入れたあと、サイトのフォルダで  python3 _build_hero_images.py  を実行すると
assets/heroes/ に 144px の画像が作られ、シミュレーター・英雄一覧・世代別ページ・左英雄チェッカーに表示されます。
画像を入れていない英雄は、これまで通りの兵種アイコンで表示されます。
このフォルダは「_」で始まるため公開されません。
